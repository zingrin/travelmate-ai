# TravelMate AI Backend

This folder contains a lightweight backend service for the TravelMate AI app.

## Available endpoints

- `GET /api/health`
- `GET /api/faqs`
- `GET /api/packages`
- `GET /api/search?q=your+query`
- `POST /api/contact`

## Run locally

1. Navigate to the backend folder:

```bash
cd backend
```

2. Install dependencies:

```bash
npm install
```

3. Start the server:

```bash
npm run dev
```

The backend will run on `http://localhost:4000`.
